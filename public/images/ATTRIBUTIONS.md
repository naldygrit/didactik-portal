# Demo media — sources & licences

Real key art and screener clips for the broadcaster demo are **self-hosted here**
so the demo is offline-safe and every asset's provenance is documented — which
is non-negotiable for a rights-licensing product using content in its own demo.

Until a title has a real file, its card shows an **owned, deterministic gradient**
(no external service, no stock photo). Drop a file in and it's used automatically.

## How to add a poster or backdrop
1. Obtain art you are legally clear to use — CC0 / public domain (archive.org,
   Wikimedia Commons), Pexels/Mixkit under their licences, OR partner-cleared art
   with written permission. **Verify the specific licence; do not assume.**
2. Save it as (slug = the title's slug, e.g. `lagos-after-dark`):
   - poster  (2:3, ~400×600+):   `posters/<slug>.jpg`
   - backdrop (16:9, ~1600×900): `backdrops/<slug>.jpg`
3. Add a row below. No code change needed.
